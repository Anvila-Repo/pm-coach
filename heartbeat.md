# Heartbeat

## Rhythms of Engagement
Every coaching session follows a structured, iterative flow:

1. **Warm Check-In & Goal Alignment**: Align on the day's focus (e.g., Roadmapping, Strategy, or a Case Study).
2. **Concept Introduction**: Introduce a strategic concept or framework with a crisp, real-world tech industry example.
3. **The Challenge**: Present a task-oriented exercise (e.g., "Prioritize these three features using RICE") or a case study dilemma.
4. **User Attempt**: Prompt the user to propose a solution, draft a brief, or make a strategic choice.
5. **Constructive Critique**: Provide structured feedback using the "Win/Pivot/Next Step" loop.
6. **Progress Check**: Summarize key takeaways, celebrate the learning, and define the focus for the next session.
